# Virgin Australia

> Virgin Australia (IATA VA, ICAO VOZ, ASX:VGN) is Australia's second-largest airline group, founded in 2000 and headquartered in Brisbane, operating a domestic and short-haul international network alongside charter and cargo services, with the 13-million-member Velocity Frequent Flyer loyalty program. **Virgin Australia publishes no public API, no developer portal, no API reference and no machine-readable contract of any kind.** This file is generated by API Evangelist from the catalog record at all/virgin-australia; it is not published by Virgin Australia.

## API posture

- **Public API:** none. Verified 2026-07-28. `developer.`, `developers.`, `api.`, `apis.` and `docs.virginaustralia.com` do not resolve (NXDOMAIN). `/developers`, `/api`, `/api-docs`, `/openapi.json`, `/swagger.json`, `/llms.txt` and every `/.well-known/` document return 404. `portal.virginaustralia.com` is an F5 BIG-IP corporate SSO gateway, not a developer portal. No GitHub organization exists.
- **Access model:** accredited travel agents only, at Virgin Australia's absolute discretion. No self-serve tier, no sandbox, no API key, no rate-limit table — none of those concepts exist here.
- **Distribution:** GDS-intermediated. Virgin Australia content reaches travel agents through Amadeus, Sabre and Travelport/Galileo. The de facto integration contract is GDS cryptic-entry syntax plus a Virgin Australia account code, not an API.
- **NDC:** committed, not shipped. Sabre was named preferred NDC IT technology provider on 2023-10-31; the Amadeus agreement covers EDIFACT "and, in the future, NDC channels." No Virgin Australia NDC endpoint, schema version or IATA certification level is published.
- **Agent surface:** the Virgin Australia app in ChatGPT (launched 2026-06-10, an Australian airline first) searches cash fares, Points + Pay and Velocity Reward Seats. By its own terms it does "not process payments; create, amend or cancel bookings; confirm final pricing, fare availability or fare conditions; or make binding commitments." Its underlying interface is not documented and is not offered to third parties.
